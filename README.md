# Birthday Sweet Coffee

Распакуйте папку и откройте index.html. Три экрана переключаются прокруткой; SCROLL на первом и втором также работает как ссылка на следующий экран.

Для публикации загрузите index.html, style.css, script.js и всю папку assets в репозиторий GitHub Pages. Не удаляйте assets: там локальные шрифты и детали утверждённого визуала.

Анимации отключаются при системной настройке уменьшения движения.
